# Despair Board — บอร์ดเกมสืบสวนฆาตกรรมบนเว็บ (แนว Danganronpa)

เกม social deduction สำหรับ 3–15 คน เล่นผ่านเบราว์เซอร์ในห้องเดียวกัน
ทุกคนถูกขังในสถานที่เดียวที่มีหลายห้อง ต้อง **สำรวจห้องหาของสำหรับหนี** ทำ **ภารกิจลับ** ให้ทัน
และระวังว่า **ใครก็ลงมือฆ่าได้** — เมื่อพบศพจะเข้าสู่รอบเก็บหลักฐานและการตัดสินแบบ Danganronpa (โหวตผิด = ทุกคนตาย)

- เซิร์ฟเวอร์: Node.js + Express + Socket.IO (`server/`)
- หน้าเว็บ: HTML/CSS/JS ล้วน ไม่ต้อง build (`public/`)
- AI: Claude API ผ่าน `@anthropic-ai/sdk` (structured output ด้วย zod) ใช้เจน Ultimate / สถานที่ / คำบรรยายคดี และมี **โหมด mock** สำรองอัตโนมัติเมื่อไม่มี API key — กลไกเกมทั้งหมด (ใครอยู่ไหน ฆ่าสำเร็จไหม) คำนวณในเซิร์ฟเวอร์ ไม่ได้ให้ AI ตัดสิน

## 1. ติดตั้งและรัน

ต้องมี Node.js 18 ขึ้นไป (ทดสอบกับ Node 26)

```bash
npm install
```

สร้างไฟล์ `.env` จากตัวอย่าง แล้วใส่ API key (ไม่ใส่ก็เล่นได้ในโหมด mock)

```bash
copy .env.example .env
```

รันเซิร์ฟเวอร์

```bash
npm start
```

เปิด <http://localhost:3000> — เพื่อนในวง Wi‑Fi เดียวกันเปิดได้ที่ `http://<IP เครื่องคุณ>:3000`
(เซิร์ฟเวอร์พิมพ์ลิงก์ให้ตอนเริ่ม) ถ้าจะเล่นข้ามอินเทอร์เน็ตดูหัวข้อ 2.5 / 2.6

ตอนพัฒนาใช้ `npm run dev` (รีสตาร์ตอัตโนมัติเมื่อแก้ไฟล์ใน `server/`)

### ตัวแปรใน `.env`

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |

| `AI_FALLBACKS` | (ว่าง) | ตั้งเป็น `off` เพื่อปิด server-side refusal fallback |
| `PORT` | `3000` | พอร์ตเว็บ |
| `MIN_PLAYERS` | `3` | ผู้เล่นขั้นต่ำ (รวมบอท) |
| `STEP_TIMEOUT_MS` | `240000` | เวลาต่อจังหวะ "เลือกห้อง" / "เลือกแอ็กชัน" หมดเวลาแล้วระบบเลือกให้เอง (`0` = ไม่จำกัด) |
| `MAX_DAYS` | `10` | จำนวนวันสูงสุด ครบแล้วเกมจบ ผู้ที่ยังอยู่ถือว่ารอด |
| `BODY_DISCOVERERS` | `3` | ต้องมีคนพบศพกี่คน (ไม่นับคนฆ่า) ถึงประกาศ (ลดเองตามจำนวนคนที่เหลือ) |

| `OBJECTIVES` | `true` | ภารกิจลับประจำวัน (ทำไม่ทัน = ตาย) ตั้ง `false` เพื่อปิด |
| `MAX_RUNOFFS` | `2` | จำนวนรอบโหวตตัดสินสูงสุดเมื่อคะแนนเสมอ ก่อนสุ่ม |
| `REVIVE_CHANCE` | `0.15` | โอกาส (0–1) เกิดอีเวนต์คืนชีพตอนเริ่มวันใหม่หลังการตัดสิน ตั้ง `0` เพื่อปิด |
| `HIDDEN_ULTIMATE_RATIO` / `HIDDEN_ULTIMATE_MAX` | `0.15` / `2` | จำนวน Ultimate ที่ซ่อนเป็น `???` = clamp(round(ผู้เล่น × RATIO), 1, MAX) |
| `FAKE_ROLES` | `1` | จำนวนโรลปลอม (Ultimate ที่คนอื่นเห็นไม่ใช่ของจริง) |

## 2. วิธีเล่น

### เป้าหมาย

- **ทุกคน**: หา **ของสำหรับหนี** (2–3 ชิ้น สุ่มซ่อนตามห้อง) ให้ครบ แล้วนำไปที่ **ห้องทางออก** พร้อมกัน → ทุกคนที่ยังมีชีวิตรอด
- **คนที่เลือกเป็นฆาตกร**: ฆ่าแล้วไม่ถูกจับ — ถ้ากลุ่มโหวตผิดในการตัดสิน คนร้ายรอดคนเดียว ทุกคนที่เหลือตาย เกมจบ
- ทุกคนมี **ภารกิจลับ** ที่ต้องทำให้ทันกำหนด ไม่ทัน = ตาย (คนอื่นเห็นแค่ศพที่ไม่มีบาดแผล ไม่รู้สาเหตุ)
- เกมยาวสูงสุด `MAX_DAYS` วัน ครบแล้วผู้ที่ยังอยู่ถือว่ารอด

### เริ่มเกม

1. **สร้างห้อง** ใส่ชื่อ → กด "สร้างห้องใหม่" ได้รหัสห้อง 4 ตัว ส่งลิงก์เชิญหรือรหัสให้เพื่อน
2. **ล็อบบี้** หัวห้องเลือกจำนวน **บอท** เพื่อเติมผู้เล่น แล้วกด "เริ่มเกม"
3. **สุ่มตัวละคร** ทุกคนได้ตัวละคร 1 ตัว (ชื่อแนวญี่ปุ่น 15 ตัวใน `server/characters.js`) และ Ultimate ที่ AI สุ่มให้
   - Ultimate ทุกอันมี **trait** ที่มีผลกับแอ็กชันจริง: **นักสู้** (ลงมือ/สวนกลับเก่ง) · **เงียบเชียบ** (ล้วงกระเป๋า ซ่อนหลักฐานเนียน) · **การแพทย์** (ตรวจศพละเอียด วางยาแม่น) · **ช่างเทคนิค** (ตัดไฟห้อง พยานจำหน้าไม่ได้) · **นักพูด** (ซักถามล้วงความจริง) · **ช่างสังเกต** (ค้นของซ่อนเจอง่าย) · หรือไม่มี
   - มีแค่ **1–2 คนที่ Ultimate ถูกซ่อนเป็น `???`** (เจ้าตัวรู้ 50/50) และ **1 คนถือโรลปลอม** (คนอื่นเห็น Ultimate ปลอม เจ้าตัวรู้ของจริง ถูกเปิดโปงเมื่อเป็นคนร้าย/ผู้ตายที่ตัดสินแล้ว หรือจบเกม)
4. AI สร้าง **สถานที่ปิดตาย 1 แห่ง** ใช้ทั้งเกม มี 8 ห้อง: ที่นอนรวม + ห้องสำรวจ 6 ห้อง (ห้องละ 2 ชิ้น: อาวุธ ยา/สารพิษ เครื่องมือ กุญแจ ผ้า แผงไฟ) + ห้องทางออก ของในห้องจะเห็นก็ต่อเมื่อเข้าไป

### ลูปของแต่ละวัน

1. **เลือกห้อง** ทุกคนเลือกพร้อมกัน ไม่มีใครเห็นว่าใครเลือกอะไร — ระบบสุ่ม "ฆาตกรประจำวัน" 1 คน (รู้แค่ตัวเอง) ให้โบนัส: รู้ว่าอาวุธอยู่ห้องไหน และโอกาสลงมือสำเร็จ +10% จะลงมือหรือไม่ก็ได้
2. **เข้าห้อง** เห็นว่าใครอยู่ห้องเดียวกับคุณ ของที่วางอยู่ และศพ (ถ้ามี) กับดักที่มีคนวางไว้อาจทำงานตอนนี้
3. **เลือกทำ 1 อย่าง**
   - 🔍 **สำรวจ** หาของที่ซ่อนอยู่ (รวมของหนี) เก็บหลักฐาน และสังเกตว่าของอะไรหายไปจากห้อง
   - 🖐 **หยิบของ** / 🫥 **ซ่อนของ** / ⬇ **วางของ** (ถือได้ `INVENTORY_MAX` ชิ้น)
   - 🔪 **ลงมือฆ่า** คนที่อยู่ห้องเดียวกัน — โอกาสสำเร็จขึ้นกับอาวุธ trait จำนวนพยาน และโบนัสฆาตกรประจำวัน ผลลัพธ์: สำเร็จเงียบ / สำเร็จแต่เลอะเทอะ (คราบ เศษผ้า เสื้อเปื้อน) / **พลาด** (เป้าหมายรู้ตัว อาจทำอาวุธหล่น) / **โดนสวนกลับตาย** / **พลาดไปโดนคนอื่นในห้อง**
   - 🪤 **วางกับดัก** ด้วยยา อาวุธ หรือเครื่องมือ — คนต่อไปที่เข้าห้อง (ที่ไม่ใช่คุณ) มีโอกาสโดน
   - 🔎 **ตรวจศพ** (trait การแพทย์รู้อาวุธ วันที่ตาย และว่าศพถูกย้ายไหม) · 🚚 **ย้ายศพ** (ทิ้งรอยลาก) · 🧹 **ทำลายหลักฐาน** (พลาดแล้วยิ่งเลอะ)
   - 🕵 **ล้วงกระเป๋า** / 🗣 **ซักถาม** / ⚡ **ตัดไฟ** ตาม trait
   - 🚪 **เปิดทางออก** ที่ห้องทางออก: นับของหนีของทุกคนที่เลือกพร้อมกัน ครบทุกชิ้น = ทุกคนที่ยังอยู่รอด
   - 😶 **สังเกต** มีโอกาสเห็นว่าใครทำอะไรลับ ๆ ล่อ ๆ
   - คนในห้องเดียวกันอาจ **เห็น** สิ่งที่คุณทำ (หยิบของ 50%, ลงมือ 40–75%, ย้ายศพ 80%…) และศพที่เกิดในห้องจะถูกคนในห้องพบแน่นอน
4. **อ่านสมุดบันทึก** ทุกอย่างที่คุณเห็นและทำวันนี้ **มีแค่คุณที่รู้** จะเล่าในแชทหรือเก็บไว้ก็ได้ ภารกิจที่ถึงกำหนดจะถูกตรวจตอนจบวัน

### ศพ รอบเก็บหลักฐาน และการตัดสิน

- ศพอยู่ที่ตาย (ของที่ผู้ตายถือหล่นไว้ในห้องนั้น รวมของหนี) จนกว่าจะมีคนย้าย คนที่เข้าห้องจะ "พบศพ" แต่ **จะบอกใครหรือไม่ก็ได้**
- เมื่อมีคนพบศพครบ `BODY_DISCOVERERS` คน (ไม่นับคนฆ่า) → **ประกาศพบศพ** (AI บรรยายสภาพศพให้สอดคล้องกับสาเหตุจริง โดยไม่บอกใบ้คนร้าย) → **รอบเก็บหลักฐาน** 1 รอบ: ของในทุกห้องถูกจัดใหม่ ทุกคนเลือกห้อง + ทำได้ 1 อย่าง (ไม่มีภารกิจ ลงมือฆ่าไม่ได้ แต่ซ่อนหลักฐาน/ย้ายศพได้)
- **การตัดสิน** เล่าหลักฐานกันในแชท แล้วโหวตคนร้าย หรือ **"ไม่มีคนร้ายให้ลงโทษ"** (ศพจากภารกิจ / คนร้ายตายไปแล้ว)
  - โหวตถูก → คนนั้น **ถูกประหาร** เกมเดินต่อ (คะแนนเสมอ → รอบตัดสินเฉพาะตัวเลือกที่เสมอ)
  - โหวตผิด → **คนร้ายรอด ทุกคนที่เหลือถูกประหาร เกมจบ**
  - เฉลย: ใครฆ่าใคร อย่างไร ที่ไหน ใครอยู่ในห้อง ใครเห็น ฆาตกรประจำวันคือใคร และตาราง **ใครไปห้องไหนในแต่ละวัน** พร้อมเหตุการณ์จริงทั้งหมด
- เช้าวันถัดไปอาจเกิด **อีเวนต์คืนชีพ** (`REVIVE_CHANCE`, เฉพาะผู้ตายที่คดีตัดสินแล้ว คนละครั้ง)

### จบเกมเมื่อ

| เหตุการณ์ | ผล |
|---|---|
| เปิดทางออกสำเร็จ | ทุกคนที่ยังมีชีวิต **รอด** |
| โหวตผิด | คนร้าย **รอด** ทุกคนที่เหลือ **ไม่รอด** |
| เหลือผู้เล่นคนเดียว | คนนั้นรอด |
| ครบ `MAX_DAYS` วัน | ผู้ที่ยังอยู่รอด |

สรุปผลท้ายเกมแสดงแค่ **รอด / ไม่รอด** (พร้อมสาเหตุ: ถูกฆ่า เสียชีวิตปริศนา ถูกประหาร โหวตผิด) ไม่มีระบบอันดับ

### กติกาเสริมที่ระบบตัดสินใจไว้ (แก้ได้)

- ภารกิจค้างได้ทีละข้อ (วันละ 1 แอ็กชัน) แบบที่มี: ไปห้อง X / หยิบของ Y / นำของไปวางที่ห้อง Z / ไปอยู่ห้องเดียวกับ W — ถ้าเป้าหมายหายไปโดยไม่ใช่ความผิดคุณ (เช่น คนอื่นหยิบของไปก่อน) ภารกิจถูกยกเลิก ไม่ตาย
- คนที่ถูกจู่โจมแล้ว **สวนกลับจนผู้จู่โจมตาย** นับเป็นคนร้ายของคดีนั้น (ตามกติกาของสถานที่) แต่เฉลยจะบอกว่าเป็นการป้องกันตัว
- ถ้าคนร้ายตายไปก่อนการตัดสิน คำตอบที่ถูกคือ "ไม่มีคนร้ายให้ลงโทษ"
- ผู้ที่ตายแล้วดูเกมต่อได้ (เห็นตำแหน่งทุกคนและศพทั้งหมด แต่ไม่เห็นว่าใครเป็นคนร้าย) พิมพ์แชทไม่ได้จนกว่าเกมจบ
- หัวห้องกด **บังคับไปต่อ** ได้ทุกจังหวะ (คนที่ยังไม่เลือกจะอยู่ที่เดิม/อยู่เฉย ๆ) และหมดเวลา `STEP_TIMEOUT_MS` ระบบทำให้เอง
- บอทจะเดินสำรวจ ทำภารกิจ หยิบอาวุธ และถ้าถูกสุ่มเป็นฆาตกรประจำวันแล้วอยู่กับคนอื่นแค่คนเดียวก็อาจลงมือ (60%) โหวตถูก 35% ถ้าไม่ใช่คนร้าย

## 2.5 เล่นกับเพื่อน

เซิร์ฟเวอร์ฟังทุก interface (`0.0.0.0`) และหน้าล็อบบี้มีปุ่ม **🔗 คัดลอกลิงก์เชิญ** (`/?room=XXXX`) ที่เปิดแล้วกรอกรหัสห้องให้เอง ผู้เล่นแค่ใส่ชื่อแล้วกดเข้าร่วม ลิงก์ใช้ origin ที่หัวห้อง "เปิดอยู่" ดังนั้นให้หัวห้องเปิดเกมผ่านที่อยู่ที่เพื่อนเข้าถึงได้ก่อน แล้วค่อยคัดลอกลิงก์

| วิธี | เหมาะกับ | ทำอย่างไร |
|---|---|---|
| **Wi-Fi เดียวกัน (LAN)** | เล่นในบ้าน/ห้องเดียวกัน | รัน `npm start` แล้วดูบรรทัด "เพื่อนใน Wi-Fi เดียวกันเข้าได้ที่ http://192.168.x.x:3000" ส่งลิงก์นั้นให้เพื่อน (ถ้าเข้าไม่ได้ ให้ Windows Firewall อนุญาต Node.js บนเครือข่ายส่วนตัว) |
| **อินเทอร์เน็ต แบบชั่วคราว** | เล่นกับเพื่อนต่างที่ ไม่ต้องสมัครอะไร | ติดตั้ง [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) (`winget install Cloudflare.cloudflared`) แล้วรัน `npm run share` ควบคู่กับ `npm start` จะได้ URL `https://xxxx.trycloudflare.com` ใช้ได้จนกว่าจะปิดหน้าต่าง |
| **อินเทอร์เน็ต แบบถาวร (แนะนำ)** | เปิดห้องได้ทุกเมื่อโดยไม่ต้องเปิดคอม ไม่ต้องอยู่ Wi-Fi เดียวกัน | Deploy ขึ้น Render ฟรีผ่าน GitHub ตามหัวข้อ **2.6** ด้านล่าง (มี `render.yaml` และ `Dockerfile` ให้แล้ว) |

- ผู้เล่นที่หลุด (ปิดแท็บ/เน็ตหลุด) กลับเข้าห้องเดิมได้อัตโนมัติด้วยชื่อเดิมบนเบราว์เซอร์เดิม ระหว่างนั้นหัวห้องใช้ปุ่ม "บังคับไปต่อ" / "ปิดโหวตตอนนี้" ให้เกมเดินต่อได้
- ถ้าหัวห้องหลุด คนถัดไปจะเป็นหัวห้องแทนอัตโนมัติ ห้องที่ไม่มีใครอยู่เกิน 2 ชั่วโมงจะถูกลบ
- รองรับมือถือ (เลย์เอาต์เรียงเป็นคอลัมน์เดียว)

## 2.6 ขึ้นเซิร์ฟเวอร์จริงผ่าน Git (Render ฟรี) — ใช้เวลาราว 10 นาที

เกมเป็นเซิร์ฟเวอร์ Node ตัวเดียว (Express + Socket.IO) ห้องเก็บในหน่วยความจำ จึง deploy ได้กับโฮสต์ที่รัน Node ยาว ๆ และรองรับ WebSocket เช่น **Render** (ฟรี ไม่ต้องใส่บัตร), Koyeb, Railway, Fly.io หรือ VPS ใด ๆ ที่มี Docker
โฮสต์แบบ serverless (Vercel, Netlify, Cloudflare Pages) **ใช้ไม่ได้** เพราะไม่รองรับการเชื่อมต่อค้างไว้

### ขั้นตอน (Render)

1. โค้ดอยู่บน GitHub แล้วที่ <https://github.com/popLazySans/DetectiveSim> (ถ้าแก้โค้ดในเครื่องให้ `git push` ขึ้น `main`)
2. **สมัคร Render** ที่ https://render.com ด้วยบัญชี GitHub (ฟรี ไม่ต้องใส่บัตร)
3. กด **New +** → **Blueprint** → เลือก repo → Render จะอ่าน `render.yaml` ให้เอง → กด **Apply**
4. (ไม่บังคับ) ไปที่ service → **Environment** → ใส่ `ANTHROPIC_API_KEY` เพื่อให้ AI เจนเนื้อหาจริง ถ้าไม่ใส่เกมจะรันโหมด mock
5. รอ build 1–2 นาที จะได้ URL แบบ `https://despair-board.onrender.com` เปิดแล้วสร้างห้อง กด **🔗 คัดลอกลิงก์เชิญ** ส่งให้เพื่อนได้เลย
6. ต่อไปทุกครั้งที่ `git push` Render จะ deploy ใหม่ให้อัตโนมัติ (`autoDeploy: true`)

ถ้า repo เป็น public จะใช้ปุ่มนี้แทนข้อ 3 ได้:
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/popLazySans/DetectiveSim)

### ข้อจำกัดของแพลนฟรี Render

- ไม่มีคนใช้เกิน 15 นาทีเซิร์ฟเวอร์จะ "หลับ" เปิดครั้งแรกต้องรอปลุกราว 30–60 วินาที (หน้าเว็บจะขึ้นแถบ "กำลังเชื่อมต่อ/ปลุกเซิร์ฟเวอร์" ให้) ระหว่างเล่นหน้าเว็บส่งสัญญาณทุก 4 นาทีจึงไม่หลับกลางเกม
- ห้องอยู่ในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ต/deploy ใหม่ ห้องที่เล่นค้างอยู่จะหาย (ให้ deploy ตอนไม่มีคนเล่น)
- ฟรี 750 ชั่วโมง/เดือน สำหรับเล่นกับเพื่อนพอเหลือเฟือ

### ทางเลือกอื่น

- **Koyeb** (ฟรี ไม่ต้องใส่บัตร): Create Service → GitHub → เลือก repo → Builder เลือก **Dockerfile** → port 3000 → Deploy
- **Railway**: New Project → Deploy from GitHub → ตั้ง env `PORT` ไม่ต้องตั้ง (Railway ใส่ให้) มีเครดิตทดลองจำกัด
- **VPS/เครื่องตัวเองที่มี Docker**: `docker build -t despair-board .` แล้ว `docker run -d -p 3000:3000 -e ANTHROPIC_API_KEY=sk-... despair-board`

## 3. โหมด AI และค่าใช้จ่าย

AI ถูกเรียกน้อยลงมากเมื่อเทียบกับเวอร์ชันแรก เพราะกลไกเกมคำนวณเอง: ต่อเกมเรียกตอนเริ่ม 2 ครั้ง (Ultimate + สถานที่) และทุกครั้งที่มีการประกาศศพ 1 ครั้งต่อศพ (คำบรรยายสภาพศพ/สรุปความจริง) บวกอีเวนต์คืนชีพถ้าเกิด
แต่ละครั้งส่งราว 1–2K โทเค็นเข้า ได้ 0.5–2K โทเค็นออก ที่ราคา Opus 5.5 ($4/$20 ต่อล้านโทเค็น) เกมหนึ่งจึงอยู่ราวไม่กี่เซนต์ ถ้าอยากประหยัดตั้ง `CLAUDE_MODEL=claude-sonnet-5-5`

สิ่งที่ตั้งไว้ในโค้ด (`server/ai.js`):

- ใช้ `client.beta.messages.parse` + `betaZodOutputFormat` เพื่อให้ได้ JSON ตรงตาม schema เสมอ (`output_config.effort: medium`)
- เปิด **server-side refusal fallback** (`fallbacks: "default"`) ปิดได้ด้วย `AI_FALLBACKS=off`
- **สถานที่**: AI ต้องสร้าง 8 ห้องตามโครงที่กำหนด (ที่นอน / 6 ห้องสำรวจที่มีอาวุธ ≥4 ยา 2–3 แผงไฟ 2 กุญแจ ผ้า เครื่องมือ / ทางออก) พร้อมชื่อของหนี 4 ชื่อ ระบบตรวจจำนวนห้องและของพกพาได้ ถ้าไม่ผ่านใช้ mock
- **คำบรรยายคดี**: AI ได้รับ "ข้อเท็จจริง" ที่เอนจินคำนวณแล้ว (ใครฆ่าใคร ด้วยอะไร ที่ไหน เลอะเทอะไหม ถูกย้ายไหม) แล้วเขียน title / สภาพศพ / ความผิดปกติ / สรุปความจริง — ห้ามเปลี่ยนข้อเท็จจริง และถ้าชื่อคนร้ายหลุดในส่วนสาธารณะ ระบบจะทิ้งและใช้ mock แทน
- ตอนเริ่มเซิร์ฟเวอร์จะเช็ก credentials ด้วย `models.list` (ไม่เสียโทเค็น) ถ้าไม่ผ่านจะเป็นโหมด mock และหน้าเว็บจะแสดงป้าย `AI: Mock`

โหมด mock (`server/mock.js`) มี Ultimate 31 แบบพร้อม trait, สถานที่ 6 แห่ง (8 ห้อง) และเทมเพลตบรรยายคดีตามประเภทอาวุธ/สาเหตุ

## 4. โครงสร้างโปรเจกต์

```
server/
  index.js        Express + Socket.IO, จัดการห้องและ event จากผู้เล่น
  game.js         state machine + กลไกเกมทั้งหมด (ห้อง ของ แอ็กชัน กับดัก ศพ ภารกิจ การตัดสิน บอท มุมมองเฉพาะบุคคล)
  objectives.js   ภารกิจลับประจำวัน (สุ่ม/ตรวจผล)
  ai.js           เรียก Claude (zod schema + prompt) และ fallback ไป mock
  mock.js         Ultimate+trait, สถานที่แบบมีห้อง, คำบรรยายคดี, อีเวนต์คืนชีพ สำหรับโหมดไม่มี API key
  characters.js   ตัวละคร 15 ตัว (ชื่อ ลักษณะ นิสัย)
public/
  index.html / style.css / app.js   หน้าเว็บทั้งหมด (render จาก state ที่เซิร์ฟเวอร์ส่งมาเฉพาะบุคคล)
test/
  simulate.js     จำลอง 13 เกมด้วย mock ตรวจการซ่อนข้อมูล ลูปวัน กับดัก ภารกิจ การตัดสิน การหนี
```

เซิร์ฟเวอร์ส่ง `state` ที่ **กรองแล้วเฉพาะผู้เล่นคนนั้น** (`Game.viewFor(playerId)`): ตำแหน่งคนอื่น (เว้นคนที่อยู่ห้องเดียวกัน) ของที่คนอื่นถือ ของที่ซ่อนอยู่ สมุดบันทึกของคนอื่น ฆาตกรประจำวัน และตัวตนคนร้าย ไม่ถูกส่งไปที่เบราว์เซอร์ของคนที่ไม่มีสิทธิ์เห็นเลย แม้แต่การตายก็รู้ต่อเมื่อพบศพเอง/ถูกประกาศ

## 6. สิ่งที่ยังไม่มี / ต่อยอดได้

- ห้องเก็บในหน่วยความจำ ถ้ารีสตาร์ตเซิร์ฟเวอร์เกมที่ค้างอยู่จะหาย
- ยังไม่มีระบบล็อกอิน ใครรู้รหัสห้องก็เข้าได้ (เหมาะกับเล่นในกลุ่มเพื่อน)
- ตัวละคร 15 ตัวเป็น mock ถ้าต้องการให้ AI สุ่มชื่อ/ลักษณะด้วย เพิ่มฟังก์ชันใน `ai.js` คล้าย `generateUltimates`
- ค่าความน่าจะเป็นของแอ็กชัน (โอกาสลงมือ กับดัก สำรวจเจอ) อยู่ใน `server/game.js` (`WEAPON_BASE`, `attackChance`, `CONFIG.*_CHANCE`) ปรับสมดุลได้
- ไอเดียเพิ่ม: แชทกระซิบในห้องเดียวกัน, อีเวนต์พิเศษชนิดอื่นนอกจากคืนชีพ, เสียง/เอฟเฟกต์ตอนประกาศศพ, บันทึกเกมเป็นไฟล์
